# Embedded-системы

Embedded-системы предназначены для узкого круга задач. Они не рассчитаны для того, чтобы ими пользовались люди, кроме наладчика или администратора, они просто выполняют определённый ряд задач, ограничиваясь только нужным функционалом.

Используются такие системы в бытовой электронике, транспорте, промышленности, медицине, связи, компьютерной периферии и торговле.

При этом есть Windows Embedded, которая позволяет пользоваться почти как обычной системой, но используется в основном в торговой технике и банкоматах, например. Она имеет расширенный срок поддержки – выпуска обновлений безопасности.
